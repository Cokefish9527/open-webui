# 回收站完整测试脚本使用说明

## 概述

本脚本集成了完整的回收站测试功能，支持以下测试类型：

1. **完整工作流测试** - 基础的5步文件夹测试流程
2. **简单快速测试** - 基础功能验证
3. **回收站完整测试** - 完整的9步回收站测试流程 ⭐️ **新增**
4. **回收站修复验证** - 验证回收站接口修复 ⭐️ **新增**

## 🚀 快速开始

### 1. 启动测试

```bash
# Windows 环境
cd c:\work\open-webui\backend
run_folder_tests.bat
```

### 2. 选择测试类型

运行脚本后，会看到以下菜单：

```
请选择要运行的测试类型：
[1] 完整工作流测试 (详细的5步测试流程)
[2] 简单快速测试 (基础功能验证)
[3] 回收站完整测试 (完整的9步回收站测试流程)      ⭐️ 新增
[4] 回收站修复验证 (验证回收站接口修复)          ⭐️ 新增
[5] 退出
```

## 🔧 配置说明

### 认证配置

在运行测试前，需要配置认证信息。有两种方式：

#### 方式1: 使用Token（推荐）

编辑以下文件，替换token：

- `test_recovery_complete_workflow.py` (第57行)
- `test_recovery_fixes.py` (第41行)

```python
# 替换这行
preset_token = "your_test_token_here"
# 为
preset_token = "实际的有效token"
```

#### 方式2: 使用用户名密码

编辑相同文件，配置用户名密码：

```python
# 替换这些行
TEST_EMAIL = "admin@example.com"
TEST_PASSWORD = "admin123"
# 为实际的用户名密码
```

### 服务器配置

确保后端服务正在运行：
- 默认地址: `http://localhost:8080`
- 如需修改，请编辑脚本中的 `BASE_URL` 变量

## 📋 回收站完整测试流程

**测试选项3** 会执行完整的9步回收站测试：

### 步骤详解

1. **登录认证** 🔐
   - 尝试使用预设token
   - 失败则尝试用户名密码登录
   - 验证token有效性

2. **获取目录** 📁
   - 获取目录列表
   - 验证回收站虚拟目录是否存在
   - 检查目录结构

3. **创建目录** ✨
   - 智能选择父目录（优先子目录）
   - 创建测试专用目录
   - 保存目录ID供后续使用

4. **上传素材** 📤
   - 创建测试文件
   - 上传到新建目录
   - 记录素材ID和原始目录ID

5. **移入回收站** 🗑️
   - 调用软删除接口
   - 记录原始目录信息
   - 验证删除操作

6. **验证在回收站** ✅
   - 检查素材是否在回收站列表中
   - 验证素材不再存在于原目录
   - 确认软删除生效

7. **还原素材** 🔄
   - 调用还原接口（无需传递target_directory）
   - 验证还原到正确的原始目录
   - 检查素材重新出现在原目录

8. **永久删除** ❌
   - 调用永久删除接口
   - 彻底删除素材和文件
   - 记录删除操作

9. **验证彻底删除** 🏁
   - 确认素材不在原目录中
   - 确认素材不在回收站中
   - 完成完整测试流程

## 🔍 回收站修复验证

**测试选项4** 会验证回收站接口修复情况：

### 验证内容

1. **虚拟目录验证**
   - 检查获取目录接口是否返回回收站虚拟目录
   - 验证回收站ID为 "recovery"
   - 确认label字段正确

2. **还原接口验证**  
   - 测试还原接口不再要求target_directory参数
   - 验证接口参数简化
   - 确认自动还原逻辑

3. **批量操作验证**
   - 测试批量还原不再要求target_directory
   - 验证批量操作接口修复
   - 确认接口兼容性

## 🛠️ 故障排除

### 常见问题

1. **认证失败**
   ```
   ❌ Token认证: 预设token无效
   ```
   **解决**: 检查token配置，确保使用有效token

2. **服务器连接失败**
   ```
   ❌ 请求失败: Connection refused
   ```
   **解决**: 确保后端服务运行在 `http://localhost:8080`

3. **权限不足**
   ```
   ❌ 创建目录: 403 Forbidden
   ```
   **解决**: 检查用户权限，确保有操作权限

4. **回收站功能异常**
   ```
   ❌ 回收站验证: 素材未在回收站中找到
   ```
   **解决**: 检查软删除逻辑和数据库状态
