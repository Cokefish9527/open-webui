# n8n工作流集成的对话消息转发服务优化

## Core Features

- 基于对话入口的智能工作流路由

- 爆款学习工作流的循环调用策略

- 定时策略控制系统

- 视频分析工作流的内部调用限制

- WebSocket实时消息转发

- 结构化响应处理

- 系统监控和健康检查

## Design

实现了基于对话入口点的智能工作流协同系统，根据不同的对话场景自动选择合适的n8n工作流（主工作流或信息收集工作流），同时为爆款学习工作流实现了独立的循环调用策略和定时控制，确保视频分析工作流仅限于n8n内部调用
