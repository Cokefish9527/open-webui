# 端到端WebSocket工作流测试计划

## 目标
测试完整的端到端流程：运行服务端程序，通过WebSocket连接向服务端发送消息，服务端构建请求结构，自动路由到对应工作流的Webhook地址，向工作流发送请求，并将工作流返回的消息结构化处理后发送给调用者。

## 测试环境
- Python版本: 3.11
- 项目路径: D:\Work\hsch\open-webui
- 服务端口: 8081

## 测试组件

### 1. 服务端组件
- WebSocket端点: `/ws/hsai/ws/{user_id}`
- 工作流路由: 根据消息内容路由到不同的n8n工作流
- Webhook调用: 向n8n工作流发送请求
- 响应处理: 结构化处理工作流响应并返回给客户端

### 2. 客户端组件
- WebSocket客户端连接
- 消息发送
- 响应接收

## 测试场景

### 场景1: 基本对话消息处理
1. 客户端通过WebSocket连接到服务端
2. 发送简单文本消息"你好"
3. 服务端接收消息并路由到主对话工作流
4. 服务端向n8n工作流发送请求
5. 接收工作流响应并结构化处理
6. 将响应发送回客户端

### 场景2: 工作流触发消息处理
1. 客户端通过WebSocket连接到服务端
2. 发送工作流触发消息（包含特定关键字）
3. 服务端识别为工作流触发消息
4. 路由到相应的工作流Webhook
5. 服务端向n8n工作流发送请求
6. 接收工作流响应并结构化处理
7. 将响应发送回客户端

### 端到端测试脚本
```python
# test_full_websocket_workflow_flow.py
import asyncio
import websockets
import json
import aiohttp
import logging

# 配置日志
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# WebSocket服务器地址
WS_URL = "ws://localhost:8081/ws/hsai/ws/test_user"

# 测试消息
test_messages = [
    {
        "type": "chat",
        "content": "你好"
    },
    {
        "type": "workflow_trigger",
        "content": "执行工作流测试"
    }
]

async def test_websocket_workflow():
    """测试WebSocket工作流端到端流程"""
    logger.info("开始WebSocket工作流端到端测试")
    
    try:
        # 连接到WebSocket服务器
        logger.info(f"连接到WebSocket服务器: {WS_URL}")
        async with websockets.connect(WS_URL) as websocket:
            logger.info("WebSocket连接成功建立")
            
            # 发送测试消息
            for i, message in enumerate(test_messages):
                logger.info(f"发送测试消息 {i+1}: {message}")
                
                # 发送消息
                await websocket.send(json.dumps(message))
                logger.info("消息发送成功")
                
                # 等待响应
                try:
                    response = await asyncio.wait_for(websocket.recv(), timeout=30.0)
                    logger.info(f"收到响应 {i+1}: {response}")
                    
                    # 解析响应
                    try:
                        response_data = json.loads(response)
                        logger.info(f"响应数据结构: {json.dumps(response_data, ensure_ascii=False, indent=2)}")
                    except json.JSONDecodeError:
                        logger.warning("响应不是有效的JSON格式")
                        
                except asyncio.TimeoutError:
                    logger.error("等待响应超时")
                    
    except Exception as e:
        logger.error(f"测试过程中发生错误: {e}")

if __name__ == "__main__":
    asyncio.run(test_websocket_workflow())
```
