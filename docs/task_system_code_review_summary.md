## 1. 检查目标

根据任务系统设计文档(task_system_design.md)检查当前项目中的任务系统实现情况，重点关注：
1. 关键节点时接收到blue_image_content时能否在hsai_extraction_blueprint根据session_id、user_id获取到正确的数据
2. 能否在蓝图数据的基础上进行主线任务的模板调用，添加主线任务到公司负责人账号
