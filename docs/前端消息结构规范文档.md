# 前端消息结构规范文档

## 1. 前端发送给服务端的消息结构

### 1.1 消息结构定义

```json
{
  "type": "chat",              // 消息类型，可选值："chat"(聊天消息) | "workflow_trigger"(工作流触发)
  "content": "你好",           // 用户输入的对话文字内容
  "user_id": "user_123",       // 用户唯一标识符
  "session_id": "session_456", // 会话ID，用于维持对话上下文（可选）
  "entry_type": "chat",        // 对话入口类型，可选值："chat"(普通聊天) | "company"(公司信息) | "business"(商业分析) | "video_publish"(视频发布)（可选）
  "task_id": "task_789",       // 关联的任务ID（可选）
  "metadata": {                // 元数据信息（可选）
    "timestamp": 1640995200,   // 时间戳
    "client_version": "1.0.0"  // 客户端版本
  }
}
```

### 1.2 字段说明

| 字段名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| type | string | 是 | 消息类型，可选值："chat"(聊天消息) \| "workflow_trigger"(工作流触发) |
| content | string | 是 | 用户输入的对话文字内容 |
| user_id | string | 是 | 用户唯一标识符 |
| session_id | string | 否 | 会话ID，用于维持对话上下文 |
| entry_type | string | 否 | 对话入口类型，可选值："chat"(普通聊天) \| "company"(公司信息) \| "business"(商业分析) \| "video_publish"(视频发布) |
| task_id | string | 否 | 关联的任务ID |
| metadata | object | 否 | 元数据信息 |

### 1.3 metadata字段说明

| 字段名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| timestamp | integer | 否 | 时间戳 |
| client_version | string | 否 | 客户端版本 |

### 1.4 注意事项

- session_id为可选字段，如果未提供，服务端会自动生成
- entry_type用于服务端判断使用哪个工作流
- task_id用于关联特定任务（如果适用）
