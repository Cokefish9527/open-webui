## 问题诊断与改进
- 组织/流程
  - 症结：PM/需求治理缺位；外包沟通滞后（>7 天）；冻结点执行弱。
  - 行动：指定临时 PM（20% 工时）；建立“变更评审单+决策日志”；外包响应 SLA≤48h。
- 架构/路线
  - 症结：对 n8n 过度耦合；社媒方案未定；跨系统无补偿/回放。
  - 行动：主链路“服务编排 + 事件驱动”，n8n 收敛为外围工具；对比云手机 vs Playwright（合规/成本/并发/维护/切换）；补幂等键、重试、死信、补偿日志与回放脚本。
- 工程化
  - 症结：测试/CI/观测/密钥全缺。
  - 行动：补 3–5 条主链路 E2E（含失败重试）；CI 触发 Lint+E2E；结构化日志+核心指标与告警；引入最小 Secret 管理（生产不落盘凭据）。
- 合规/安全
  - 症结：Open WebUI 品牌/License 未决；TikTok ToS 风险不明；仅 DB 备份加密与 OSS 临时授权。
  - 行动：短期仅内部使用；推进框架替换选型；输出 TikTok ToS 风险评估与预案；安全基线：强口令/MFA、后台全审计、IP 白名单（后台）、逐日备份验证。

## 近期交付与验收
- 你方 2 周 DoD：产品规划功能全部可跑通流程（收集→素材→绑定→合成→发布）。
- 建议 Beta 验收
  - 主链路 E2E 通过率≥95%，关键路径恢复≤30 分钟；
  - 发布成功率≥90%，失败可回滚/重试；合成耗时≤成品时长；
  - API 成功率≥99.5%，对话单次响应≤30 秒（含状态同步）；
  - 观测：成功率/失败率/耗时 P95 可见；错误可溯源（任务/账号/公司 ID）。
