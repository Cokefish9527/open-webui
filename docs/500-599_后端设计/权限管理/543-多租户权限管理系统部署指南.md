# 多租户权限管理系统部署指南

## 1. 概述

本文档详细说明如何部署和配置多租户权限管理系统，包括环境准备、数据库配置、应用部署和系统初始化等步骤。

## 2. 系统要求

### 2.1 硬件要求
- CPU: 2核或以上
- 内存: 4GB或以上
- 磁盘空间: 20GB或以上可用空间

### 2.2 软件要求
- 操作系统: Linux (Ubuntu 20.04+/CentOS 7+/Debian 10+) 或 Windows Server 2016+
- Python版本: 3.11+
- 数据库: PostgreSQL 12+ 或 SQLite 3.35+
- Web服务器: Nginx 1.18+ 或 Apache 2.4+
- Node.js: 16+ (用于前端构建)

## 3. 环境准备

### 3.1 Python环境配置
```bash
# 安装Python 3.11
sudo apt update
sudo apt install python3.11 python3.11-venv python3.11-dev

# 创建虚拟环境
python3.11 -m venv openwebui-env
source openwebui-env/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 3.2 数据库配置

#### 3.2.1 PostgreSQL配置
```sql
-- 创建数据库
CREATE DATABASE openwebui_multitenant;

-- 创建用户
CREATE USER openwebui_user WITH PASSWORD 'secure_password';

-- 授权
GRANT ALL PRIVILEGES ON DATABASE openwebui_multitenant TO openwebui_user;
```

#### 3.2.2 环境变量配置
在 `.env` 文件中添加以下配置：
```env
# 数据库配置
DATABASE_URL=postgresql://openwebui_user:secure_password@localhost:5432/openwebui_multitenant

# 多租户配置
ENABLE_MULTI_TENANCY=true
TENANT_ISOLATION_MODE=DATABASE  # 或 SCHEMA

# 安全配置
WEBUI_SECRET_KEY=your_secret_key_here
JWT_EXPIRES_IN=7 days
```

## 4. 应用部署

### 4.1 代码获取
```bash
git clone https://github.com/your-org/open-webui.git
cd open-webui
```

### 4.2 依赖安装
```bash
# 激活虚拟环境
source openwebui-env/bin/activate

# 安装Python依赖
pip install -r requirements.txt

# 安装前端依赖
npm install
```

### 4.3 数据库迁移
```bash
# 初始化数据库
python backend/open_webui/manage.py migrate

# 创建初始数据
python backend/open_webui/manage.py loaddata initial_data.json
```

### 4.4 应用配置

#### 4.4.1 配置文件修改
编辑 `backend/open_webui/config.py` 文件：
```python
# 启用多租户支持
ENABLE_MULTI_TENANCY = os.environ.get("ENABLE_MULTI_TENANCY", "true").lower() == "true"

# 租户隔离模式
TENANT_ISOLATION_MODE = os.environ.get("TENANT_ISOLATION_MODE", "DATABASE")

# 组织管理配置
ENABLE_ORGANIZATION_MANAGEMENT = True
```

#### 4.4.2 权限配置
在 `backend/open_webui/config.py` 中添加多租户权限配置：
```python
# 多租户权限配置
MULTI_TENANT_PERMISSIONS = {
    "system_admin": {
        "can_manage_organizations": True,
        "can_manage_all_users": True,
        "can_access_all_data": True,
    },
    "org_admin": {
        "can_manage_org_users": True,
        "can_manage_org_projects": True,
        "can_access_org_data": True,
    },
    "org_member": {
        "can_access_assigned_data": True,
        "can_manage_personal_data": True,
    }
}
```

## 5. 系统初始化

### 5.1 创建系统管理员
```bash
python backend/open_webui/manage.py createsuperuser \
    --email admin@system.com \
    --name "System Administrator" \
    --is_super_admin true
```

### 5.2 创建初始组织
使用API或管理界面创建第一个组织：
```bash
curl -X POST "http://localhost:8080/api/v1/organizations" \
  -H "Authorization: Bearer <admin_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Default Organization",
    "description": "系统默认组织"
  }'
```

### 5.3 配置组织管理员
为组织指定管理员用户：
```bash
curl -X POST "http://localhost:8080/api/v1/organizations/{org_id}/users/{user_id}" \
  -H "Authorization: Bearer <admin_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "is_org_admin": true
  }'
```

## 6. 启动服务

### 6.1 后端服务启动
```bash
# 激活虚拟环境
source openwebui-env/bin/activate

# 启动后端服务
cd backend
python open_webui/main.py
```

### 6.2 前端服务启动
```bash
# 构建前端
npm run build

# 启动前端服务
npm run start
```

### 6.3 使用进程管理器
推荐使用 `supervisor` 或 `pm2` 管理服务进程：

#### 6.3.1 使用PM2
```bash
# 安装PM2
npm install -g pm2

# 启动后端服务
pm2 start backend/open_webui/main.py --name "openwebui-backend"

# 启动前端服务
pm2 start npm --name "openwebui-frontend" -- run start

# 保存配置
pm2 save
```

## 7. 反向代理配置

### 7.1 Nginx配置
```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /api/ {
        proxy_pass http://localhost:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /ws/ {
        proxy_pass http://localhost:8080/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 9. 备份和恢复

### 9.1 数据库备份
```bash

pg_dump -h localhost -U openwebui_user -d openwebui_multitenant > backup.sql

# SQLite备份
cp openwebui.db openwebui.db.backup
```

### 9.2 数据恢复
```bash

# SQLite恢复
cp openwebui.db.backup openwebui.db
```

## 10. 故障排除

### 10.1 常见问题

#### 10.1.1 权限不足错误
**问题现象**：访问API时返回403错误
**解决方案**：
1. 检查用户角色和权限配置
2. 确认用户已正确分配到组织
3. 验证JWT token是否有效

#### 10.1.2 数据库连接失败
**问题现象**：应用启动时数据库连接失败
**解决方案**：
1. 检查数据库服务是否运行
2. 验证数据库连接字符串配置
3. 确认数据库用户权限

#### 10.1.3 组织数据无法访问
**问题现象**：用户无法访问所属组织的数据
**解决方案**：
1. 检查用户organization_id字段是否正确设置
2. 验证组织关联数据是否完整
3. 确认查询逻辑中的组织过滤条件

### 10.2 日志分析
```bash
# 查看应用日志
tail -f logs/openwebui.log

# 查看错误日志
grep "ERROR" logs/openwebui.log

# 查看审计日志
tail -f logs/audit.log
```

## 11. 升级维护

### 11.1 版本升级
```bash
# 停止服务
pm2 stop openwebui-backend openwebui-frontend

# 拉取最新代码
git pull origin main

# 更新依赖
pip install -r requirements.txt
npm install

# 执行数据库迁移
python backend/open_webui/manage.py migrate

# 重启服务
pm2 start openwebui-backend openwebui-frontend
```

### 11.2 配置更新
在升级后检查并更新配置文件：
1. 比较新旧配置文件差异
2. 根据需要更新环境变量
3. 验证配置项的兼容性

## 12. 安全建议

### 12.1 访问控制
1. 定期审查用户权限分配
2. 实施最小权限原则
3. 启用多因素认证(MFA)

### 12.2 数据保护
1. 启用数据库加密
2. 定期备份数据
3. 实施数据访问审计

### 12.3 网络安全
1. 使用HTTPS加密传输
2. 配置防火墙规则
3. 定期更新系统和依赖包
