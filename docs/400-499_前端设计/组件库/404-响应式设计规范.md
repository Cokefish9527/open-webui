## 1. 响应式设计原则

### 1.1 设计理念

**桌面优先** - 以桌面端体验为基准，向下适配  
**渐进增强** - 核心功能在所有设备上可用，高级功能按需增强  
**内容优先** - 确保核心内容在任何屏幕上都能良好呈现  
**性能优化** - 不同设备加载适合的资源  

### 1.2 设计目标

| 目标 | 桌面端 | 平板端 | 移动端 |
|------|--------|--------|--------|
| 可用性 | 完整功能 | 核心功能 | 关键功能 |
| 性能 | 丰富交互 | 平衡体验 | 快速响应 |
| 布局 | 多列布局 | 双列布局 | 单列布局 |
| 交互 | 鼠标+键盘 | 触摸+鼠标 | 触摸为主 |

## 2. 断点系统

### 2.1 断点定义

```css
/* 断点变量定义 */
:root {
  --breakpoint-xs: 480px;   /* 超小屏幕 */
  --breakpoint-sm: 640px;   /* 小屏幕 */
  --breakpoint-md: 768px;   /* 中等屏幕 */
  --breakpoint-lg: 1024px;  /* 大屏幕 */
  --breakpoint-xl: 1280px;  /* 超大屏幕 */
  --breakpoint-2xl: 1536px; /* 2K屏幕 */
}

/* 媒体查询 Mixins */
@mixin mobile-up {
  @media (min-width: var(--breakpoint-xs)) { @content; }
}

@mixin tablet-up {
  @media (min-width: var(--breakpoint-md)) { @content; }
}

@mixin desktop-up {
  @media (min-width: var(--breakpoint-lg)) { @content; }
}

@mixin large-desktop-up {
  @media (min-width: var(--breakpoint-xl)) { @content; }
}
```

## 3. 布局适配策略

### 3.1 对话工作台布局

#### 3.1.1 桌面端布局 (1280px+)

```css

.chat-layout {
  display: flex;
  height: 100vh;
}

.chat-left,

  flex: 1;
  min-width: 0;
}

.chat-left {
  border-right: 1px solid var(--border-color);
}
```

#### 3.1.2 平板端布局 (768-1279px)

```css
/* 平板端：可切换的单面板 */
@media (max-width: 1279px) {
  .chat-layout {
    position: relative;
  }
  
  .chat-left,
  .chat-right {
    width: 100%;
```

## 10. 最佳实践

### 10.1 开发建议

1. **移动优先开发**: 从最小屏幕开始设计
2. **渐进增强**: 基础功能优先，增强功能后加
3. **内容优先**: 确保核心内容在所有设备上可用
4. **性能监控**: 定期检测不同设备上的性能

### 10.2 设计建议

1. **简化移动端界面**: 减少不必要的元素
2. **增大触摸目标**: 按钮至少44px×44px
3. **优化阅读体验**: 合适的字体大小和行高
4. **提供快捷操作**: 移动端的便捷操作入口
