# 任务指派人功能实现说明

## 概述

本文档详细说明了在HSAI任务管理系统中添加任务指派人功能的实现过程。该功能允许用户将任务指派给特定的用户，并支持按指派人查询任务。

## 功能需求

1. 支持在创建任务时指定指派人
2. 支持更新任务的指派人
3. 支持按指派人查询任务
4. 支持通过专门的API端点指派任务

## 实现细节

### 1. 数据库模型更新

在`HSAITask`模型中添加了`assignee_id`字段：

```python

```

### 2. 数据库迁移

创建了数据库迁移脚本`hsai_002_add_assignee_to_tasks.py`：

```python
def upgrade():
    """Add assignee_id column to hsai_tasks table"""
    op.add_column('hsai_tasks', sa.Column('assignee_id', sa.String(), nullable=True))
    op.create_index('ix_hsai_tasks_assignee_id', 'hsai_tasks', ['assignee_id'])

def downgrade():
    """Remove assignee_id column from hsai_tasks table"""
    op.drop_index('ix_hsai_tasks_assignee_id', table_name='hsai_tasks')
    op.drop_column('hsai_tasks', 'assignee_id')
```

## 使用示例

### 创建带指派人的任务

```bash
curl -X POST "http://localhost:8080/hsai/tasks/" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "测试任务",
    "description": "这是一个测试任务",
    "task_type": "video_creation",
    "assignee_id": "user_123"
  }'
```

### 更新任务指派人

```bash
curl -X PUT "http://localhost:8080/hsai/tasks/$TASK_ID" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "assignee_id": "user_456"
  }'
```

### 按指派人查询任务

```bash
curl -X GET "http://localhost:8080/hsai/tasks/?assignee_id=user_456" \
  -H "Authorization: Bearer $TOKEN"
```

### 专门的指派接口

```bash
curl -X POST "http://localhost:8080/hsai/tasks/$TASK_ID/assign?assignee_id=user_789" \
  -H "Authorization: Bearer $TOKEN"
```
