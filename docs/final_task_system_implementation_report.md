## 3. 接口实现详情

### 3.1 任务列表接口
1. **通过用户ID获取任务列表**
   - 路径：`GET /api/v1/hsai/tasks/`
   - 功能：获取当前用户的所有任务，支持分页和过滤
   - 过滤条件：状态、任务类型、指派人、聊天会话ID

2. **通过企业名称获取任务列表**
   - 路径：`GET /api/v1/hsai/tasks/by-company/{company_name}`
   - 功能：获取指定企业关联项目下的所有任务，支持分页和过滤
   - 过滤条件：状态、任务类型

### 3.2 任务操作接口
- 任务创建：`POST /api/v1/hsai/tasks/`
- 任务详情：`GET /api/v1/hsai/tasks/{task_id}`
- 任务更新：`PUT /api/v1/hsai/tasks/{task_id}`
- 任务删除：`DELETE /api/v1/hsai/tasks/{task_id}`

### 3.3 循环任务接口
- 激活循环任务：`POST /api/v1/hsai/tasks/{task_id}/recurring/activate`
- 暂停循环任务：`POST /api/v1/hsai/tasks/{task_id}/recurring/pause`
- 恢复循环任务：`POST /api/v1/hsai/tasks/{task_id}/recurring/resume`
- 外部托管循环任务：`POST /api/v1/hsai/tasks/{task_id}/recurring/handover`
- 同步外部状态：`POST /api/v1/hsai/tasks/{task_id}/recurring/sync`
- 模拟调度：`POST /api/v1/hsai/tasks/{task_id}/simulate`
- 查看状态日志：`GET /api/v1/hsai/tasks/{task_id}/recurring/logs`

### 3.4 项目摘要接口
- 项目摘要：`GET /api/v1/hsai/projects/{project_id}/summary`

## 5. 业务逻辑实现

### 5.1 蓝图同步流程
1. 接收blue_image_content消息
2. 从n8n数据库获取最新蓝图数据
3. 定位或创建用户项目
4. 同步蓝图数据到主蓝图进度表
5. 基于蓝图模板创建或更新任务
6. 生成每日循环子任务（如适用）

### 5.2 任务创建流程
1. 用户或系统触发任务创建
2. 验证任务参数和权限
3. 创建任务记录
4. 如指定聊天会话，创建对应的任务卡片
5. 通过WebSocket通知前端

### 5.3 循环任务调度流程
1. 检查循环任务状态
2. 验证前置任务完成情况
3. 根据配置生成子任务
4. 更新任务调度时间
5. 记录状态变更日志
