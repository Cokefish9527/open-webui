# WebSocket 调试页+任务系统联动改造计划（含后端接口）

> 在前端优化基础上，进一步扩展任务系统调试能力，需要新增后端接口、数据模型及脚本支撑；目标是覆盖蓝图摘要、循环任务运行态与状态日志的全流程联动。

## 1. 目标与范围
- **项目摘要接口**：实现 `GET /api/v1/hsai/projects/{project_id}/summary`，聚合项目基本信息、最新蓝图进度（版本、同步时间、计划截止日）以及主线任务完成度。
- **循环任务运行态**：扩展 `hsai_tasks` 模型和数据库，新增循环状态字段、外部控制标识、运行时间戳；同步提供状态日志表以便调试面板查询。
- **状态控制接口**：面向后台/调试页面提供激活、暂停、恢复、交接、同步等 REST 端点，附带状态机校验与错误反馈。
- **前端联动**：调试面板调用新接口，支持查看项目摘要、循环状态、日志记录和外部同步结果。
- **知识库同步**：在 `PROJECTWIKI.md` 建立蓝图→任务→通知链路的双向映射，并更新手册说明。

## 2. 交付物
1. 数据层更新：
   - ORM 模型（`hsai_tasks.py`、`hsai_blueprint_progress.py`）拓展循环字段与 Pydantic 模型。
   - 新表 `hsai_task_state_logs` + 数据迁移脚本 `tool/add_recurring_task_fields.py`（幂等、dry-run）。
2. 后端服务：
   - `blueprint_sync_service.py` 适配新字段、写入状态日志。
   - 任务路由新增项目摘要接口与循环状态控制端点（`activate/pause/resume/handover/sync/logs`）。
   - 单元测试覆盖摘要聚合、状态迁移合法性、日志写入/查询、脚本执行。
3. 前端调试页：
   - `static/ws-tester.js` 增加项目摘要请求、循环状态按钮、日志展示。
   - UI 展示蓝图版本、同步时间、计划截止日、循环运行态与日志筛选。
4. 文档同步：
   - `PROJECTWIKI.md` 数据模型、流程、API 与调试工具更新。
   - `docs/410_websocket_test_page_manual.md` 补充项目摘要步骤与循环控制说明。

## 5. 风险与应对
- **数据库兼容性**：脚本需检测列/表存在，避免重复执行；提供回滚 SQL。
- **状态机复杂度**：限定合法迁移路线（idle→active→paused 等），异常时输出明确错误码与日志；编写单元测试。
- **接口权限**：循环控制接口需要复用后台鉴权策略，必要时添加角色校验或签名。
- **前后端节奏不一致**：制定 Mock 数据或 Feature Flag，使前端在后台未部署时可降级展示。

## 6. 验证策略
- 自动化：pytest 覆盖摘要聚合、循环状态迁移、日志写入；脚本 dry-run + 实际执行检查。
- 手动：通过调试面板逐步验证摘要刷新、状态控制、日志回显与蓝图通知。
- 回归：确保旧任务操作（创建、更新、重放）不受影响，必要时运行冒烟测试。
