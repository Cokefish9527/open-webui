## 📅 拍摄频率建议

| 类型 | 建议频次 | 备注 |
| --- | --- | --- |
| 企业/工厂形象 | 每季度一次 | 如搬迁/新设备需补拍 |
| 生产制造流程 | 每季度更新一次 | 新产品/新工艺更新 |
| 质检/测试 | 每季度一次 | 如无变化可半年一次 |
| 包装/装柜 | 每月一次 | 每批产品差异化拍摄 |
| 出货/物流 | 每月一次 | 不同目的地可多样化 |
| 参展/洽谈 | 每次参展后补拍 | 确保最新的展会内容 |
| 客户应用 | 每月最少2次 | 不同行业场景拍摄 |
| 教学操作 | 产品更新时同步 | 保证指导片段实时性 |
| 企业文化 | 每半年一次 | 新荣誉/文化墙变化 |
| CTA | 季度更新 | 保持文案与话术新颖 |
