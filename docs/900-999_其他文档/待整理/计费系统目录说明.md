# HSAI计费系统

## 概述

HSAI计费系统是为了解决HSAI项目中大模型集成在n8n中无法有效获取token消耗、多种第三方服务计费方式不同以及Redis连接不稳定导致计费风险等问题而设计的。该系统采用基于资源消耗的计费模式，通过数据库持久化存储确保计费数据的可靠性和一致性。

## 系统架构

计费系统主要由以下几个组件构成：

1. **计费配置管理** - 管理各种资源的计费比率和规则
2. **API使用记录** - 记录第三方API调用的使用情况
3. **计费服务** - 核心计费逻辑处理
4. **公司积分管理** - 管理公司账户的积分余额

## 计费模式

系统采用基于资源消耗的计费模式，主要包括：

1. **存储资源** - 按存储空间大小和时间收费（2积分/GB/月）
2. **第三方API调用** - 按调用次数收费（0.1积分/次）

## 核心功能

### 1. 计费配置管理
- 支持动态配置各种资源的计费比率
- 提供API接口进行配置的增删改查
- 配置存储在数据库中，支持后台随时调整

### 2. API使用记录
- 记录每次第三方API调用的详细信息
- 支持按会话ID查询使用记录
- 提供积分消耗统计功能

### 3. 计费处理
- 自动处理任务完成信号并触发计费
- 计算资源使用费用
- 更新公司积分余额

### 4. 积分管理
- 实时跟踪公司积分余额变化
- 支持积分充值和消费
- 提供余额不足提醒功能

## 数据库设计

### 计费配置表 (billing_config)
存储各种资源的计费配置信息。

### API使用记录表 (hsai_business_api_usage_log)
记录第三方API调用的使用情况。

## API接口

详细的API接口说明请参考 [计费系统API接口文档](计费系统API接口文档.md)。

## 使用流程

1. **配置计费比率** - 管理员通过后台配置各种资源的计费比率
2. **记录API调用** - 系统在每次API调用后记录使用情况
3. **计算费用** - 根据计费比率和使用量计算费用
4. **更新余额** - 扣除公司账户的积分余额
5. **生成报表** - 提供计费统计报表和消费分析

## 注意事项

1. 系统采用数据库而非Redis进行关键计费记录，避免了Redis连接丢失导致的计费风险
2. 调用次数与积分换算的配置存储在数据库中，方便后台随时调整
3. 所有计费操作都包含事务处理，确保数据一致性
4. 提供完善的日志记录和异常处理机制
