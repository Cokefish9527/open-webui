## 1. 页面概述

### 1.1 功能定位
素材管理页面提供企业级文件管理功能，支持多格式文件的上传、分类、搜索和预览，是内容创作的重要支撑工具。

### 1.2 核心特性
**目录树结构** - 层级目录管理，支持无限嵌套  
**多格式支持** - 图片、视频、音频、文档等多种格式  
**批量操作** - 支持多文件选择和批量处理  
**智能搜索** - 基于文件名、标签、内容的搜索功能

## 4. 文件上传功能

### 4.1 上传方式

#### 4.1.1 拖拽上传
```javascript
class DragUploadHandler {
  constructor(dropZone) {
    this.dropZone = dropZone;
    this.initEventListeners();
  }
  
  initEventListeners() {
    this.dropZone.addEventListener('dragover', this.handleDragOver.bind(this));
    this.dropZone.addEventListener('drop', this.handleDrop.bind(this));
  }
  
  handleDrop(event) {
    event.preventDefault();
    const files = Array.from(event.dataTransfer.files);
    this.processFiles(files);
  }
  
  processFiles(files) {
    files.forEach(file => {
      if (this.validateFile(file)) {
        this.uploadFile(file);
      }
    });
  }
}
```

#### 4.2.2 批量上传队列
```javascript
class UploadQueue {
  constructor() {
    this.queue = [];
    this.uploading = false;
    this.maxConcurrent = 3;
  }
  
  addFiles(files) {
    files.forEach(file => {
      this.queue.push({
        file,
        status: 'pending',
        progress: 0
      });
    });
    
    this.processQueue();
  }
  
  processQueue() {
    if (this.uploading) return;
    
    const pendingFiles = this.queue.filter(item => item.status === 'pending');
    const uploading = this.queue.filter(item => item.status === 'uploading');
    
    if (pendingFiles.length > 0 && uploading.length < this.maxConcurrent) {
      this.uploading = true;
      this.uploadNext();
    }
  }
}
```

## 6. 搜索功能

### 6.1 搜索类型

#### 6.1.1 基础搜索
```javascript
function basicSearch(keyword) {
  const results = fileData.filter(file => 
    file.name.toLowerCase().includes(keyword.toLowerCase()) ||
    file.tags.some(tag => tag.toLowerCase().includes(keyword.toLowerCase()))
  );
  
  updateFileGrid(results);
  showSearchResults(keyword, results.length);
}
```

#### 6.1.2 高级搜索
```javascript
function advancedSearch(criteria) {
  let results = fileData;
  
  // 按文件类型过滤
  if (criteria.type) {
    results = results.filter(file => file.type === criteria.type);
  }
  
  // 按大小范围过滤
  if (criteria.sizeMin || criteria.sizeMax) {
    results = results.filter(file => {
      const size = file.size;
      return (!criteria.sizeMin || size >= criteria.sizeMin) &&
             (!criteria.sizeMax || size <= criteria.sizeMax);
    });
  }
  
  // 按时间范围过滤
  if (criteria.dateStart || criteria.dateEnd) {
    results = results.filter(file => {
      const date = new Date(file.createdAt);
      return (!criteria.dateStart || date >= criteria.dateStart) &&
             (!criteria.dateEnd || date <= criteria.dateEnd);
    });
  }
  
  return results;
}
```

## 7. 批量操作

### 7.1 文件选择

#### 7.1.1 多选机制
```javascript
class FileSelection {
  constructor() {
    this.selectedFiles = new Set();
    this.shiftStartIndex = -1;
  }
  
  toggleSelection(fileId, event) {
    if (event.ctrlKey || event.metaKey) {
      // Ctrl+点击：切换单个文件选择状态
      this.toggleSingle(fileId);
    } else if (event.shiftKey) {
      // Shift+点击：选择范围
      this.selectRange(fileId);
    } else {
      // 普通点击：只选择当前文件
      this.selectOnly(fileId);
    }
    
    this.updateSelectionUI();
  }
  
  selectAll() {
    const visibleFiles = getCurrentVisibleFiles();
    visibleFiles.forEach(file => {
      this.selectedFiles.add(file.id);
    });
    this.updateSelectionUI();
  }
  
  clearSelection() {
    this.selectedFiles.clear();
    this.updateSelectionUI();
  }
}
```
