# 矩阵管理演示说明

**页面文件**: `prototypes/matrix-management.html`  
**页面状态**: 核心功能完成  
**最后更新**: 2025-08-22  

## 1. 页面概述

### 1.1 功能定位
矩阵管理页面是社媒矩阵营销的核心控制台，提供多平台账号管理、内容发布、数据分析等功能，帮助企业实现社媒营销的规模化和自动化。

### 1.2 核心特性
- **多平台集成**: 支持抖音、小红书、微博、B站等主流平台
- **统一发布**: 一键多平台内容发布和定时发布
- **数据聚合**: 各平台数据汇总分析和报表生成
- **智能推荐**: 基于数据的内容和发布时间推荐

### 3.2 平台分布图表

支持动态图表展示各平台粉丝分布、互动数据等关键指标。

## 4. 账号管理功能

### 4.1 账号卡片

每个社媒账号以卡片形式展示，包含：
- 平台标识和连接状态
- 账号基本信息（头像、昵称、粉丝数）
- 快捷操作按钮（发布、分析、设置）

### 4.2 账号状态

| 状态 | 标识 | 颜色 | 可用操作 |
|------|------|------|----------|
| 已连接 | ✓ | 绿色 | 发布、分析、设置 |
| 未连接 | × | 红色 | 重新连接 |
| 授权过期 | ⚠ | 黄色 | 刷新授权 |
| 授权中 | ○ | 灰色 | 取消授权 |

### 4.3 添加新账号

点击"添加账号"按钮，弹出平台选择界面：
- 支持的平台：抖音、小红书、微博、B站等
- OAuth授权流程
- 授权成功后自动添加到账号列表

## 5. 内容发布功能

### 5.1 发布编辑器

- **媒体上传**: 支持拖拽上传视频/图片
- **文本编辑**: 多行文本输入，字数限制提示
- **话题标签**: 智能推荐相关话题标签
- **平台选择**: 勾选目标发布平台
- **定时发布**: 可设置定时发布时间
- **可见性设置**: 公开/仅粉丝/私密

### 5.2 发布预览

支持各平台发布预览，确保内容格式适配。

### 5.3 发布队列

- 实时显示发布进度
- 支持批量发布管理
- 失败重试机制

### 5.4 发布历史

展示历史发布记录，包含：
- 内容缩略图和标题
- 发布平台和状态
- 基础数据统计（曝光、互动）
- 操作按钮（查看数据、再次发布）

## 6. 数据分析功能

### 6.1 时间范围选择

支持预设时间范围（近7天、近30天、近3个月）和自定义时间范围。

### 6.2 关键指标

- 总曝光量
- 互动总数  
- 新增粉丝
- 平均互动率

### 6.3 数据图表

- **趋势图**: 各平台曝光量、互动量随时间变化
- **对比图**: 不同内容类型的表现对比
- **分布图**: 平台粉丝分布饼图

### 6.4 平台对比表

表格形式展示各平台的详细数据对比，包括粉丝数、发布数、曝光量、互动率等。
